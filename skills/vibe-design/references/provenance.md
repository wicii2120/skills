## Normative primary standards

Normative claims derive from primary standards, which take precedence over editorial sources and examples:

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/) — semantics, contrast, color, reflow, text spacing, targets, input, motion, flashing, status, errors, and non-text content.
- [WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/) and [Accessible Name and Description Computation 1.2](https://www.w3.org/TR/accname-1.2/) — roles, states, names, and descriptions where native semantics are insufficient.
- [HTML Living Standard](https://html.spec.whatwg.org/) — semantic elements, controls, embedded content, and responsive images.
- [CSS Color 4](https://www.w3.org/TR/css-color-4/), [CSS Color Adjustment 1](https://www.w3.org/TR/css-color-adjust-1/), [CSS Values and Units 4](https://www.w3.org/TR/css-values-4/), [CSS Fonts 4](https://www.w3.org/TR/css-fonts-4/), [CSS Text 3](https://www.w3.org/TR/css-text-3/), [CSS Grid 1](https://www.w3.org/TR/css-grid-1/), [CSS Flexbox 1](https://www.w3.org/TR/css-flexbox-1/), [CSS Containment 3](https://www.w3.org/TR/css-contain-3/), and [Media Queries 5](https://www.w3.org/TR/mediaqueries-5/) — portable web rendering and user preferences.
- [SVG 2](https://www.w3.org/TR/SVG2/) — vector icon/graphic semantics and rendering.
- [Design Tokens Format Module](https://tr.designtokens.org/format/) from the W3C Design Tokens Community Group — token types, groups, values, and aliases.

Cite exact WCAG success criteria for normative requirements. Stricter values are product requirements when explicitly adopted.
